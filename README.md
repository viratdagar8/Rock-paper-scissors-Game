#  Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**. Play against the computer and test your luck in this classic game.

##  Live Demo

 https://viratdagar8.github.io/Rock-paper-scissors-Game/

##  Features

-  Play against the computer
-  Random computer choice every round
-  Instant result display (Win, Lose, or Draw)
-  Responsive design
-  Clean and attractive user interface
-  Beginner-friendly JavaScript project

##  Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

##  How to Run Locally

1. Clone this repository

```bash
git clone https://github.com/viratdagar8/Rock-paper-scissors-Game.git
```

2. Open the project folder.

3. Double-click **index.html** or open it in your browser.

No additional installation is required.

##  Game Rules

-  Rock beats Scissors
-  Scissors beats Paper
-  Paper beats Rock
- Same choices result in a Draw.
